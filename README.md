# status

Аварийная страница статуса: https://status.lenargum.me

Работает на GitHub Pages, независимо от основного сервера, поэтому доступна, даже когда он лежит.

## Как поменять статус (с телефона)

Откройте `status.json` в GitHub → карандаш «Edit» → поправьте → «Commit changes». Обновится через 1–2 минуты.

| Поле | Значение |
|---|---|
| `state` | `ok` — работает (зелёный), `warn` — перебои/работы (жёлтый), `down` — не работает (красный) |
| `title` | Короткий заголовок, одна строка |
| `text` | Что случилось и что делать |
| `updated` | Дата/время обновления, как удобно, например `15.11 18:30` |
| `channel` | Ссылка на канал с новостями; пустая строка `""` прячет кнопку |

Кавычки `"` внутри текста ставить нельзя — используйте «ёлочки».
